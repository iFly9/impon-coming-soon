# IMPON — Coming Soon

Independent React + Vite site for IMPON.

## Run locally
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL Vite prints.

## Build
Run `npm run build`; Netlify publish directory is `dist`.
